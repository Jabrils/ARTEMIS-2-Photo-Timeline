# Design: Promo Widget & Attribution Footer

**Mode**: from-scratch
**Finding**: F1 — No promo widget or attribution footer in HUD
**Tracker**: docs/findings/2026-05-18_1200_promo_attribution_FINDINGS_TRACKER.md

---

## Objective

Add a small fixed bottom-right widget to the HUD with:
1. CTA: "Like this tool? Support my work by playing my game & watch my youtube."
2. Attribution footer: "This project is inspired by [artemistimeline.com](https://artemistimeline.com/)" (clickable link, opens in new tab)

---

## Design Decision

**New `PromoWidget` component rendered absolutely in `HUD.tsx`.**

Positioned `absolute bottom-20 right-2 sm:bottom-24 sm:right-4` (above the progress bar row). Styled to match HUD aesthetic: dark semi-transparent bg, cyan border, small mono text. No store access, no state — purely presentational.

### Layout

```
┌─────────────────────────────────────────┐
│ Like this tool? Support my work by      │
│ playing my game & watch my youtube.     │
│─────────────────────────────────────────│
│ This project is inspired by             │
│ artemistimeline.com ↗                   │
└─────────────────────────────────────────┘
```

- Outer div: `bg-[rgba(10,10,30,0.85)] backdrop-blur-sm border border-[rgba(0,212,255,0.2)] rounded-lg px-3 py-2 w-56 sm:w-64`
- CTA line: `text-[10px] text-gray-300 leading-snug`
- Divider: `border-t border-[rgba(0,212,255,0.1)] mt-2 pt-2`
- Attribution: `text-[9px] text-gray-500` with `<a>` styled `text-[#00d4ff]/70 hover:text-[#00d4ff] underline`

---

## Scope

### In Scope
- New file: `src/hud/PromoWidget.tsx`
- `src/hud/HUD.tsx` — import and place `<PromoWidget />`

### Out of Scope
- No dismissal/close button (always visible)
- No store, no animation
